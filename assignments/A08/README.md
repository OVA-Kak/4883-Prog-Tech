# Number of Islands - A08 - 200
## Charles Zecha
### Input
The input contains an m x n 2D binary grid "grid" which represents a map of '1's (land) and '0's (water).

m == grid.length

n == grid[i].length

1 <= m, n <= 300

grid[i][j] is '0' or '1'.

### Output
Return the number of islands.
