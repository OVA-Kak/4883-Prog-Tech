# Last Stone Weight - A06 - 1046
## Charles Zecha
### Input
The input contains an array of integers stones where stones[i] is the weight of the i<sup>th</sup> stone.

1 <= stones.length <= 30

1 <= stones[i] <= 1000

### Output
The weight of the last remaining stone. If there are no stones left, return 0.
