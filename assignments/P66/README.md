# Plus One - 66
## Charles Zecha
### Input
The input contains a large integer represented as an integer array digits, where each digits[i] is the ith digit of the integer. The digits are ordered from most significant to least significant in left-to-right order. The large integer does not contain any leading 0's.
1 <= digits.length <= 100
0 <= digits[i] <= 9

Increment the large integer by one and return the resulting array of digits.
### Output
True if x is a palindrome, and false otherwise.
