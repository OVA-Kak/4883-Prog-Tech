# How Many Numbers Are Smaller Than the Current Number - 1365
## Charles Zecha
### Input
The input contains the array nums.

2 <= nums.length <= 500

0 <= nums[i] <= 100

### Output
For each nums[i] find out how many numbers in the array are smaller than it. That is, for each nums[i] you have to count the number of valid j's such that j != i and nums[j] < nums[i].
